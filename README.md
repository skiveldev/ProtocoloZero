# Protocolo Zero

[⬇ Descargar videojuego para Windows](https://github.com/skiveldev/ProtocoloZero/releases/download/untagged-bffb4a318e8e4ce034c3/ProtocoloZero-Windows-x64.zip)

## Cómo jugar

1. Descarga el archivo ZIP desde el enlace anterior.
2. Extrae completamente el ZIP en una carpeta, conservando todos sus archivos.
3. Ejecuta `ProtocoloZero.exe` desde la carpeta extraída.

El ejecutable no requiere instalar Unity. La opción **Code > Download ZIP** descarga el código fuente, no el videojuego.

## Controles

- **WASD:** moverse.
- **Shift:** correr.
- **E:** interactuar.

## Objetivo

Consigue las tres tarjetas de acceso, activa el panel de seguridad y llega a la salida.
